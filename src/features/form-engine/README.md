# ⚡ Janata CBS Form Engine (`@/features/form-engine`)

A high-density, schema-driven dynamic form presentation engine designed for **Janata CBS Workbench**.

Built with **React 19**, **Next.js 16**, and **Zustand**, the Form Engine consumes canonical `FormConfigRecord` layouts generated by [`@/lib/cbs-form-spec`](../../lib/cbs-form-spec/README.md). It delivers zero-latency per-keystroke input handling, automated schema validation, reactive cascading rules, and two-tier form state management.

## ⚡ Two-Tier State Architecture

To eliminate typing lag in enterprise forms with 100+ fields, the engine employs a two-tier state model:

1. **Tier 1 (Ephemeral Kernel Store)**:
   - Powered by scoped Zustand store (`form-kernel-store.ts`).
   - Fields mutate locally without triggering full form re-renders.
   - `FieldAtom` selectively subscribes only to `values[path]`.
2. **Tier 2 (Committed Record Store)**:
   - Emits consolidated delta records via `onRecordChange` upon blur, commit, or explicit tab changes.
   - Triggers server sync and Four-Eyes maker-checker validation flows.
